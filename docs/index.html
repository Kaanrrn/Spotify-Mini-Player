GOOD TO KNOW

Quick answers.

Do I need Spotify Premium?

No. The app works with free Spotify accounts.

Does it use the Spotify API?

No. It reads the Windows system media session, so no Spotify API, Premium account or Client ID is required.

Are lyrics available for every song?

Not every song has synced lyrics available. Lyrics are provided by LRCLIB, and an internet connection is needed to fetch them.

Can I control Spotify remotely?

No. The widget provides playback controls through Windows media controls, but choosing songs or opening playlists is done in Spotify itself.
